# Storyframe — Animated Book Explanations

Landing page for a YouTube channel that turns bestselling books into short animated explainer videos.

## Structure

- `index.html` — single-page site (hero, video showcase, topics, about, subscribe, contact)
- `css/style.css` — dark theme, responsive layout, animations
- `js/script.js` — mobile nav toggle + subscribe form handling

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
